# Установка discourse-reliable-push 0.1.0

**Важно:** архив содержит код для Discourse 2026.10, но он не запускался на вашей конкретной установке. Сначала установите на тестовом экземпляре форума или сделайте полный бэкап и предусмотрите откат.

1. Распакуйте ZIP. Поместите **содержимое каталога** `discourse-reliable-push` в корень своего публичного GitHub-репозитория (в корне должен находиться `plugin.rb`).
2. На сервере Discourse откройте `/var/discourse/containers/app.yml` и добавьте `git clone https://github.com/ВАШ_ЛОГИН/discourse-reliable-push.git` в `hooks.after_code[...].exec.cmd` (рядом с существующими плагинами).
3. Из каталога `/var/discourse` выполните `./launcher rebuild app`. Обычного `restart` для установки нового плагина недостаточно.
4. В админке Discourse найдите `reliable_push_enabled` и включите его. Проверьте штатные `push_notifications_prompt`, настройки Web Push/VAPID и Chat.
5. Откройте форум в установленном PWA (на iPhone — с домашнего экрана), войдите в свой профиль → настройки → уведомления. Найдите блок «Надёжные Web Push».
6. Нажмите «Включить на этом устройстве», при необходимости разрешите системные уведомления. Дождитесь «Подключено», затем «Отправить тестовый push». Тест отправляется через Sidekiq.
7. Протестируйте упоминание на форуме, затем Chat-канал с уровнем «Всегда», затем чат с «Упоминания» и с «Никогда». Убедитесь, что запреты соблюдаются.

## Откат

В конфигурации отключите `reliable_push_enabled` (если админка работает), затем удалите строку `git clone` для плагина из `app.yml` и повторите `./launcher rebuild app`. Дополнительных таблиц БД плагин не создаёт, штатные подписки остаются в `PushSubscription` ядра.

## Что ещё не входит в v0.1.0

Собственная очередь retry/outbox, гарантия доставки и уведомления Voice о входе в комнату. Форумные и Chat push отправляет штатный Discourse с его настройками и ограничениями.
